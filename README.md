# conttables2

A [jamovi](https://www.jamovi.org) module that clones jmv's **Contingency Tables** (Independent
Samples) analysis, extending its comparative measures (odds ratio, log odds ratio, relative risk,
difference in proportions) from 2x2-only to **2xK tables**: each non-reference category of the
compared variable (`compare`: rows or columns) is contrasted against a reference category (the
first level), as long as the other variable has exactly two categories. All other functionality
is unchanged from jmv.

Appears in jamovi's menu as **Frequencies > Contingency Tables > Independent Samples (2xK)**,
alongside jmv's own "Independent Samples" entry.

Built as a staging area for a future PR back to [jamovi/jmv](https://github.com/jamovi/jmv) — only
`conttables2/R/contTables.b.R` differs in substance from jmv's own `conttables.b.R`.

## Installation (sideload)

Prebuilt `.jmo` files are attached to the [Releases](../../releases) page, one release per
jamovi/R version. Pick the file matching your OS and jamovi's bundled R version (check
**Help -> About** in jamovi), then in jamovi: **Modules -> jamovi library -> Sideload** and select
the downloaded `.jmo`.

## Repository layout

- `conttables2/` — R package source (analysis definitions, R code, jamovi UI yaml)
- `tools/` — build and install helper scripts
- `dist/` — packaged `.jmo` build output per R version/OS/arch, generated by
  `tools/prepare-jmo.sh`/`tools/release.sh` (not tracked in git; attached to releases)

## Building

```
bash tools/install.sh desktop   # builds conttables2/conttables2_<version>.jmo and installs it
                                 # into jamovi.app (macOS) using ~/R/.Rlib-arm or .Rlib-x64
bash tools/install.sh docker    # same, into a running `jamovi` Docker container (needs jmc)
bash tools/install.sh           # both, whichever are available
```

Then repackage for other jamovi/R versions and ship a release:

```
bash tools/prepare-jmo.sh 4.6.0 all     # metadata-only repackage into dist/
bash tools/release.sh 4.6.0             # + publish a GitHub release with those assets
```
